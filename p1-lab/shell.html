그래프를 읽는 방법

약물 지수와 몸의 출력은 다른 척도입니다. 두 선 사이 간격은 약의 부족량이 아닙니다. 주황선은 형이 설명한 평소 패턴을 대표 시각·중간값으로 연결한 도식이며, 확인되지 않은 OFF 구간은 비워 둡니다. 실제 기록점은 2시간 이내인 경우만 직선으로 연결합니다. 선 사이의 값은 측정값이 아닙니다. 보라색 배경은 평소 이상운동증 가능 시간대이며 오늘의 발생 기록과 다릅니다.

함께 나타난 차이

수면·식사 등의 기록이 있는 날과 없는 날의 평소 대비 출력 차이를 비교합니다.

원인을 입증하지 않습니다. 복약·기록 시각·질병 상태가 다를 수 있고, ‘미기록’은 요인이 없었다는 뜻이 아닙니다. 요인을 약물 변경의 근거로 자동 사용하지 않습니다.

예측은 얼마나 맞았나?

예측 시점 이후에 기록한 출력 중 목표 시각 ±15분 내 가장 가까운 값을 비교합니다. 0에 가까울수록 오차가 작습니다. 같은 출력이 여러 예측에 연결될 수 있으므로 건수는 독립 표본 수가 아닙니다.

표준 복약표

형이 정한 기준표입니다. 변경해도 실제 복약 기록은 바뀌지 않습니다. 단위는 mg이며 퍼킨·마도파는 레보도파 성분량을 입력합니다.

평소 출력 도식

대략적인 기준점입니다. 점수 칸을 비우면 미확인 구간으로 둡니다. 변경해도 이미 저장된 예측은 다시 계산하지 않습니다.

백업과 복원

이 기기·이 브라우저에 저장됩니다. PC와 휴대폰은 자동 동기화되지 않습니다. 브라우저 데이터 삭제 전 반드시 백업하세요.

복원 전 현재 자료를 먼저 백업합니다. 이 앱에서 만든 P1 백업만 지원합니다. 기존 약효일지 데이터에는 접근하지 않습니다.

사용 순서와 계산 범위

  1. 복약할 때 실제 시각을 확인해 기록합니다.
  2. 상태가 변할 때 출력과 필요한 요인을 기록합니다.
  3. ‘지금 기준 예측 저장’을 누릅니다. 저장된 예측은 수정되지 않습니다.
  4. 30·60·120분 뒤 실제 출력을 기록하고 검증 화면을 확인합니다.
  5. 정기적으로 JSON 백업을 내려받습니다.

처음에는 가상 날짜로 연습하거나 바로 본인 관찰 기록을 시작할 수 있습니다. API 키나 유료 AI가 필요하지 않습니다. 자동 약물 증감 지시는 제공하지 않습니다.

모형 출처와 한계

약물 모형은 luke777-cpu/parkinson의 simulation-drugmodel.js를 이번 작업 시점에 복사한 것입니다. CR과 HBS는 같은 모형, 마도파 확산정과 퍼킨 즉방은 같은 즉방 모형입니다. 퍼킨 CR 별칭을 연결했습니다. 원래 엔진의 미라팩스·아만타딘 반복 복용 누적 및 아질렉트 평탄 배경 가정을 유지합니다. 따라서 ‘실제 확인된 복약만’도 배경약의 과거 반복 복용을 가정하며 실제 혈중농도가 아닙니다. 전날 레보도파는 이번 그래프에 포함하지 않습니다. 이 엔진은 임상 검증된 개인 약동학 모델이 아닙니다.
