# P1 나의 약효 실험실 1.0

형의 표준 복약표와 출력 패턴을 출발점으로, 실제 기록·차이 탐색·예측 검증을 수행하는 독립 오프라인 앱입니다. 기존 parkinson 앱과 데이터는 변경하지 않습니다.

## 스마트폰 웹 실행

https://luke777-cpu.github.io/parkinson/p1-lab/ 에서 실행합니다.
아이폰은 Safari의 공유 → 홈 화면에 추가, 안드로이드는 Chrome 메뉴 → 홈 화면에 추가로 등록합니다.
첫 온라인 방문 후 P1 전용 서비스 워커가 앱 화면을 캐시합니다. 기록은 브라우저 저장소에만 남으며 PC와 자동 동기화되지 않습니다. 오프라인 사용 전 한 번 다시 열어 캐시 설치가 완료되었는지 확인하세요.

기존 약효일지의 저장 키를 읽거나 변경하지 않습니다. 저장소 루트 sw.js에는 P1 경로 제외와 P1 캐시 보존만 적용합니다.

## 가장 간단한 실행

`P1-Lab.html`을 내려받아 PC 크롬 또는 엣지에서 엽니다. 인터넷과 API 키가 필요하지 않습니다. HTML 한 파일에 화면·계산 엔진이 모두 들어 있습니다.

일상 기록에는 고정 주소로 실행하는 아래 방법을 권합니다. 브라우저의 로컬 파일 저장 정책은 환경별로 다르므로 HTML을 옮기거나 이름을 바꾸기 전 JSON 백업을 받으세요.

## Windows에서 고정 주소로 실행

1. ZIP을 **모두 압축 해제**합니다.
2. `start.bat`을 실행합니다. Python이 설치되어 있어야 하며 추가 패키지는 필요하지 않습니다.
3. 자동으로 열리는 `http://127.0.0.1:8879`를 즐겨찾기에 등록합니다.
4. 터미널은 켜 둡니다. 다음에는 같은 폴더의 `start.bat`만 실행합니다.

배치 파일 실행이 허용되지 않는 환경에서는 해당 폴더에서 터미널을 열고 `python serve.py`를 실행하세요. 시스템 보안 설정을 해제할 필요는 없습니다. 서버는 이 PC에서만 연결할 수 있습니다. 폰으로 보거나 PC·폰을 동기화하는 서버 기능은 이 버전에 포함하지 않았습니다.

## 사용

- **실제 복약**: 해당 약의 ‘복용 기록’을 눌러 실제 시각·용량을 확인합니다. 표준표는 자동 투약 기록이 아닙니다.
- **출력**: 상태가 달라질 때 −10/+10 또는 슬라이더 → ‘출력 기록’. 과거 날짜·시각도 직접 선택할 수 있습니다.
- **요인**: 식사·수면 부족·변비·운동·이상운동증·동결을 필요한 때만 기록합니다.
- **예측**: 오늘 ‘지금 기준 예측 저장’ → 목표 시각 근처 실제 출력 기록 → ‘예측 검증’ 확인.
- **백업**: ‘표준·백업·도움말’에서 JSON 백업. JSON은 전체 복원, CSV는 기록 열람용입니다.
- **인쇄**: 원하는 화면을 선택한 뒤 인쇄합니다. 브라우저에서 PDF 저장도 가능합니다.

기록은 현재 브라우저의 localStorage에만 있습니다. 외부로 전송하지 않으며 다른 브라우저·기기와 공유되지 않습니다. 시크릿 모드와 브라우저 데이터 삭제에 주의하고, 정기적으로 백업하세요. 기존 약효일지의 JSON과 호환되지 않으며 기존 기록을 자동으로 가져오지 않습니다.

## 현재 완성 범위

표준·실제·예측 겹친 그래프, 실제 기록 수정/삭제/삭제 취소, 규칙 기반 30·60·120분 예측 보존, 사후 오차 비교, 요인 관련성 집계, JSON 복원·CSV·인쇄를 구현했습니다.

이것은 **사용 가능한 첫 실험판**입니다. 개인화 AI 학습, 인과 추론의 검증, 처방 변경, 자동 ON 판정, 웨어러블 연동, 알림, 계정/클라우드 동기화, 기존 앱 데이터 연동은 포함하지 않습니다.

## 개발자

- `shell.html`: 화면·스타일
- `core.js`: 표준값·검증·출력 예측·오차 평가·요인 집계
- `app.js`: 화면·입력·기기 내 저장·백업
- `engine.js`: 기존 parkinson 약물 곡선 엔진 복사본
- `build.py`: HTML 재생성
- `tests.cjs`: 코어 및 JSDOM UI 동작 시험 (개발 환경만 Node·jsdom 필요)
- `serve.py`: 선택적인 PC 전용 서버

재빌드: `python build.py`
테스트: `npm install` 후 `npm test`

원 엔진 출처: https://github.com/luke777-cpu/parkinson/blob/main/simulation-drugmodel.js
이번 복사본에 연결한 퍼킨 CR 별칭 외에 원 엔진의 곡선 공식은 수정하지 않았습니다. 버전별 원격 엔진 변경은 자동 반영하지 않습니다.
