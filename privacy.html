약효일지 개인정보 처리방침

최종 수정일: 2026-11-22

1. 기본 원칙 — 기기 안 저장

약효일지는 기본 상태에서 회원가입, 로그인, 서버 전송이 없습니다. 사용자가 입력하는 복약 시간, 상태(ON/OFF/전환기), 증상, 생활 기록 등 모든 데이터는 사용자의 기기 안(브라우저 localStorage)에만 저장되며, 개발자를 포함한 어떠한 외부 서버로도 전송되지 않습니다.

아래 2항의 "클라우드 연동(시험)"은 사용자가 직접 켜고 로그인한 경우에만 동작하는 선택 기능입니다. 켜지 않으면 1항이 그대로 적용됩니다.

2. 클라우드 연동(시험) — 선택 기능

현재 시험 단계이며, 운영자가 발급한 시험 계정으로만 사용할 수 있습니다.

2-1. 서버에 저장되는 정보

  • 계정 정보: 로그인 이메일과 계정 식별자(Supabase Auth). 비밀번호는 원문으로 되돌릴 수 없는 해시로만 보관되며 운영자도 원문을 볼 수 없습니다.
  • 사용자가 고른 기록: 업로드 미리보기에서 사용자가 선택한 복약(약 이름, mg 용량)·상태(상태값, 출력, 방향, 보행, 이상운동 강도, 정해진 증상 목록)·생활(수면·식사·운동·배변·몸 상태의 정해진 항목) 기록과 그 시각.
  • AI 에이전트가 보낸 추가 요청: 연결된 에이전트가 제안한 기록(위와 같은 항목). 사용자가 앱에서 승인한 것만 확정 기록이 되며, 승인하지 않은 요청은 72시간 뒤 만료됩니다.

2-2. 보내지 않는 정보

메모와 직접 입력한 자유 텍스트(사용자 정의 증상, '기타' 운동 이름 등), 약 목록, 복용 알림, 질문 목록, 설정, 그리고 사용자가 고르지 않은 기록은 서버로 보내지 않습니다. 자동으로 전송되는 기록은 없습니다.

2-3. 이용 목적

사용자가 연결을 허락한 AI 에이전트(예: Claude Code)가 사용자의 기록을 날짜별로 조회하고 주간 ON/OFF 관찰 요약을 만들며, 사용자의 승인을 거쳐 기록을 추가하도록 하기 위해서입니다. 요약은 기록된 시간 관계를 집계할 뿐 약효나 용량 변경을 판단하지 않습니다.

사용자가 "서버 기록 가져오기"를 누르면, 승인된 서버 기록 중 사용자가 고른 것만 이 기기 기록에 추가됩니다. 가져오기 전 기기 기록은 기기 안에 자동 백업되며 되돌릴 수 있고, 기존 기록은 바뀌지 않습니다.

2-4. 처리 위탁 및 저장 위치

  • Supabase(Supabase, Inc.): 계정 인증과 기록 저장. 데이터 저장 지역: 대한민국 서울(AWS ap-northeast-2).
  • Cloudflare Workers(Cloudflare, Inc.): AI 에이전트 요청을 Supabase로 전달하는 중계. 기록을 저장하지 않으며, 요청 내용·토큰·기록 내용을 로그로 남기지 않도록 설정되어 있습니다.

위 업체는 국외 사업자입니다. 기록은 서울 지역 서버에 저장되지만, 업체의 운영·지원 과정에서 국외에서 접근될 수 있습니다. Cloudflare Workers의 중계는 요청이 들어온 가장 가까운 지점에서 처리됩니다.

2-5. 접근 권한

AI 에이전트의 로그인 정보(자동 갱신용 토큰)는 사용자가 에이전트를 실행하는 PC의 사용자 폴더에만 저장됩니다. 각 사용자는 본인 기록만 볼 수 있습니다. 연결된 AI 에이전트는 연결된 사용자 한 명의 확정 기록 조회와 추가 요청만 할 수 있고, 기록을 직접 확정·수정·삭제할 수 없습니다. 사용자는 앱 설정의 "에이전트 연결"에서 언제든 연결을 폐기할 수 있으며, 폐기 즉시 해당 에이전트의 접근이 차단됩니다.

2-6. 보관 기간과 삭제

서버에 올린 기록은 사용자가 삭제를 요청할 때까지 보관합니다. 시험 단계에서는 앱 안에서 서버 기록을 지우는 기능이 없으므로, 계정과 서버 기록의 삭제는 아래 문의처로 요청해 주세요. 요청을 받으면 지체 없이 삭제합니다. 시험이 끝나면 시험 계정과 시험 서버의 기록을 삭제합니다. 기기 안의 기록은 클라우드 연동과 관계없이 그대로 유지됩니다.

2-7. 이용 중단

설정에서 클라우드 연동을 끄면 로그인 세션이 지워지고 더 이상 기록을 보내지 않습니다. 이미 올린 기록의 삭제는 2-6항에 따릅니다.

3. 저장 및 보관(기기 안)

기기 안의 기록은 앱을 삭제하거나 브라우저 데이터를 지우면 함께 삭제됩니다. 설정 탭의 "백업 내보내기" 또는 "원문 백업(복구용)"으로 사용자가 직접 파일로 보관할 수 있으며, 이 백업 파일은 서버로 보내지 않습니다.

4. 제3자 제공

운영자는 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 단, 2항을 사용하는 경우 2-4항의 처리 위탁과, 사용자가 직접 연결한 AI 에이전트가 사용자의 허락 범위 안에서 기록을 조회하는 경우가 있습니다.

5. 광고 및 추적

이 앱은 광고, 분석 도구(애널리틱스), 추적 스크립트를 포함하지 않습니다.

6. 의료 정보 관련 안내

약효일지는 증상·약효 패턴을 기록하고 관찰하는 개인용 도구이며, 의학적 진단이나 처방을 대체하지 않습니다. 약물 용량·복용 간격 조정은 반드시 주치의와 상의하시기 바랍니다.
